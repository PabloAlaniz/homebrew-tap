# PabloAlaniz Tap

## How do I install these formulae?

`brew install pabloalaniz/tap/<formula>`

Or `brew tap pabloalaniz/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "pabloalaniz/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
